MCP testing 


1) Common base for all MCP calls


$apiHost = "https://ca-intake-intake-dev-backend.politewater-2393db25.uaenorth.azurecontainerapps.io"

$caller = "Vijay.test_mcp@intakeagent.com"

function Invoke-Mcp($payload) {
    curl -sS -X POST "$apiHost/mcp" `
      -H "Content-Type: application/json" `
      -H "Accept: application/json, text/event-stream" `
      -H "MCP-Protocol-Version: 2025-11-25" `
      -H "X-Authenticated-User: $caller" `
      -H "X-Correlation-Id: $([guid]::NewGuid().ToString())" `
      --data $payload
}

Gate-by-gate decision values
Use the same header pattern for all of them.

Owner confirmation: decision = "approve" or "send_back"
AI CoE review: decision = "approve", "reject", or "send_back"
Criticality confirmation: decision = "approve" or "reject"
Architect review: decision = "approve", "reject", or "send_back"
Divergence approval: decision = "approve" or "reject"
